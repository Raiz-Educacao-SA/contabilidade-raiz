# Conciliação Bancária

Versão preparada para publicação com login, empresas, permissões, contas bancárias,
upload de vários extratos, armazenamento no Supabase e saldos por competência.

## Passos

1. Execute `schema.sql` no SQL Editor do Supabase.
2. Crie o primeiro usuário em Authentication > Users.
3. Cadastre uma empresa e vincule o usuário.
4. Envie os arquivos para um repositório privado no GitHub.
5. Publique pelo Streamlit Community Cloud.
6. Cadastre `SUPABASE_URL` e `SUPABASE_ANON_KEY` em Secrets.

Nunca publique a SERVICE_ROLE_KEY.
